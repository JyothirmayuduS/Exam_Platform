# Documentation map

This directory groups contributor-focused documentation so the repository root stays code-first.

## Core docs

- `SETUP.md` — local setup, Supabase/LiveKit/R2 wiring, Tauri build flow.
- `ARCHITECTURE.md` — application boundaries, ownership, and data flow.
- `ERROR_MONITORING.md` — Bugsink/Sentry integration and privacy notes.
- `PROCTORING-VALIDATION.md` — manual validation checklist for proctor AI.

## Historical docs

- `archive/COMPLETE_FEATURE_CHECKLIST.md` — retained for historical roadmap context; statuses inside are intentionally outdated.

## Intentionally retained unusual files

- `public/downloads/*` installer binaries are kept intentionally because the student download gate serves these artifacts directly in deployed builds.
